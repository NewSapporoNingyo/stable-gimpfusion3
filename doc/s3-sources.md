# S3 来源图层与蒙版

## 来源与参数

生成窗口的“输入来源”显示目标图像、来源层名称、尺寸、偏移和缩略图。来源采用当前选中图层列表的第一层。
打开窗口、切换模式、重新获得焦点和生成前刷新来源。预览与请求使用同次读取的像素；生成后的放置使用该次偏移。
文生图显示接收图像和选区范围，结果蒙版使用生成时取得的选区。

局部重绘采用当前选区，选区为空时采用来源图层蒙版。选区按来源偏移转换到图层坐标，蒙版与来源图层同宽高。
白色参与重绘，黑色保留；反转开关通过 `inpainting_mask_invert` 交给 Forge。
图生图要求来源图层；重绘还要求有效蒙版区域。界面显示所需输入，并按输入状态和尺寸校验设置生成按钮。

| 参数 | 规则 |
| --- | --- |
| `Whole picture` | `inpaint_full_res=false`；整张来源按 `resize_mode` 适配到请求尺寸后采样、合成 |
| `Only masked` | `inpaint_full_res=true`；裁出蒙版和边距，适配采样宽高比，采样后合回来源 |
| `Only masked padding, pixels` | 0–256，默认 32，滑块步长 4；在 `Only masked` 下启用 |
| 新参数默认值 | `Whole picture`、padding 32 |
| 已保存预设 | 保留重绘区域；旧预设的 padding 补为原先使用的 10，保存时写入该字段 |
| 结果放置 | 保留 Forge 返回的尺寸和合成像素，图生图和重绘使用来源图层偏移 |

`sg_sources.py` 使用 GEGL 读取像素，GdkPixbuf 编码 PNG，并从同一份像素生成预览。
缓存键包含尺寸、通道数和完整像素内容的 SHA-256；缓存开关沿用现有设置。
蒙版按线性灰度读取，PNG 中的灰度值对应 GIMP 的覆盖率；选区写入结果蒙版时沿用该覆盖率。

## 开发副本验收

环境由 GIMP 插件进程确认：GIMP 3.2.6、Python 3.14.7、PyGObject 3.58.0、GTK 3.24.52、requests 2.34.2。
实际 Python 为 `C:\Program Files\GIMP 3\bin\python.exe`。

真实生成使用 `waiIllustriousSDXL_v170.safetensors`、Euler、5 步、CFG 5、seed 73003、降噪强度 0.6、蒙版模糊 0。
来源为 768×512，请求采样尺寸为 512×512，来源偏移为 `(32,24)`。

| 流程 | 请求采样尺寸 | Forge 最终返回尺寸 | GIMP 图层尺寸与位置 |
| --- | --- | --- | --- |
| `Whole picture`，选区 | 512×512 | 512×512 | 512×512，`(32,24)` |
| `Only masked`，选区，padding 0、32、128 | 512×512 | 768×512 | 768×512，`(32,24)` |
| `Only masked`，图层蒙版 | 512×512 | 768×512 | 768×512，`(32,24)` |
| `Only masked`，反转选区 | 512×512 | 768×512 | 768×512，`(32,24)` |
| 图生图，来源偏移 `(-32,-24)` | 512×512 | 512×512 | 512×512，`(-32,-24)` |
| 文生图，64×64 选区，按选区缩放插入 | 512×512 | 512×512 | 64×64，使用生成时选区蒙版 |

各次重绘插入后的 RGB 像素与 API 返回图逐像素一致。`Only masked` 的蒙版外像素保持来源内容；反转蒙版时，原白色区域保留。
生成前取得快照后切换图层并清空选区，实际请求仍采用该快照中的来源和蒙版。

在 Forge 的采样初始化回调中记录实际裁剪和合回位置。来源坐标中的选区为 `(320,208,384,272)`：

| padding | Forge 实际裁剪范围 | 合回区域尺寸 |
| --- | --- | --- |
| 0 | `(320,208,384,272)` | 64×64 |
| 32 | `(288,176,416,304)` | 128×128 |
| 128 | `(192,80,512,400)` | 320×320 |

三次使用相同来源、蒙版、seed 和采样参数，均完成真实生成。
`Whole picture` 的裁剪和合回位置为空，整张来源参与采样。

来源检查覆盖多选图层的第一层、切换、重命名、像素修改、正负偏移、部分越界、选区优先级、蒙版反转及空图层图像。
缓存开启时修改来源像素，编码随之更新。新字段完成预设保存、重载和 PDB 非交互传递。

通过 computer-use 在 GIMP 中切换来源 A、B，返回生成窗口后名称与白色、蓝色缩略图同步更新。
切换到 `Only masked` 后 padding 启用；清空选区且来源 B 缺少蒙版时显示输入提示，生成按钮禁用。
随后选择带蒙版的来源 A，窗口显示 `Source layer mask`，生成按钮恢复。
界面检查采用全屏截图。

## 不规则区域与羽化

使用椭圆主体、内部孔洞、分离矩形和 5 像素羽化构成不规则选区，包含 200 级以上灰度。
选区转换后的蒙版与 GIMP 线性灰度逐像素一致；抽查的覆盖率为 64、68、72、76、79、82、84、86，编码保持原值。

补充生成使用 seed 73005、降噪强度 1.0、`latent noise` 填充，其余采样参数沿用前述配置。
`Whole picture` 和 `Only masked` 均完成不规则选区重绘，孔洞保留来源内容。
`Only masked` 的所有零覆盖率像素逐像素保持来源内容，包含外部、孔洞和两个分离区域之间的间隙。
将同一不规则形状写入图层蒙版后再生成，灰度与零覆盖率区域同样通过检查。
文生图的结果蒙版完成羽化覆盖率写回检查，写回值与生成时的选区快照逐像素一致。
