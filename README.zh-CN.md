# Stable-Gimpfusion-3

[English](README.md) | 简体中文

在 GIMP 3.2 中通过 Stable Diffusion WebUI Forge 的 HTTP API 完成文生图、图生图、局部重绘和 ControlNet 生成。
独立常驻面板支持一边修图、一边生成，结果作为图层插入 GIMP。

项目由 [ArtBIT 的 GIMP 2.10 插件](https://github.com/ArtBIT/stable-gimpfusion)发展而来，基于
[shsmad 的 GIMP 3 版本](https://github.com/shsmad/stable-gimpfusion3)继续开发。本机验收环境为 Windows、GIMP 3.2.6、GIMP Python 3.14.7 和 Forge。

## 安装与连接

1. 将完整仓库放到 `%APPDATA%\GIMP\3.2\plug-ins\stable-gimpfusion3`，包含入口脚本、所有 `sg_*.py`、`sg_plugins` 和 `locale`。
2. 使用 GIMP 自带的 Python 确认 `import requests` 成功。解释器位于 GIMP 安装目录的 `bin\python.exe`。
3. 启动 Forge，启用 `--api`。本机入口为 `C:\data\webui_forge_dev\run-forge.bat`，参数为 `--api --cuda-malloc`。
4. 重启 GIMP，从 `GimpFusion → 配置 → 全局设置` 设置后端地址，默认 `http://127.0.0.1:7860`。
5. 打开或新建图像，从 `GimpFusion → 打开生成面板` 开始。文生图、图生图和局部重绘菜单也会打开同一面板，并选择对应模式。

插件使用 GIMP 的界面语言，提供英文、意大利文、俄文和简体中文。在 GIMP 的“编辑 → 首选项 → 界面”选择语言，重启后应用。

## 常驻面板与生成

面板顶部选择目标图像和生成模式。填写正向与负向提示词，选择模型、采样器及参数，点击“生成”。
两个提示词框均显示八行；参数、LoRA 和配置操作可展开。全局提示词后缀按“本次提示词 + 空格 + 后缀”参与请求。

seed `-1` 表示随机，`0` 至 `4294967295` 表示固定种子。“候选数量”指定一次批量生成的图像数。
宽高使用正的 8 的倍数，面板显示实际请求尺寸和插入区域。图生图和局部重绘的降噪强度越高，对来源内容的改动越大。

| 模式 | 输入与结果 |
| --- | --- |
| txt2img | 根据提示词生成；插入方式决定结果尺寸，结果定位到选区左上角。空选区采用整个画布范围 |
| img2img | 使用目标图像中第一个选中图层的完整像素；按面板尺寸生成，按来源偏移插入 |
| inpaint | 使用来源图层和蒙版；当前选区优先，随后使用来源图层蒙版；白色区域参与重绘，反转蒙版后使用黑色区域 |

“输入来源”显示目标、来源图层、缩略图、尺寸、偏移和实际蒙版来源。切换目标、改变选中图层或返回面板时刷新；生成时读取最新快照。
重绘区域 `Whole picture` 对整张来源采样；`Only masked` 对蒙版及边距采样，再合回来源尺寸。蒙版填充默认 `original`。

生成期间可以继续绘画、修改参数和切换目标。本次结果使用开始时的输入与目标，下一次生成使用最新状态。
面板一次运行一个任务。候选作为独立图层插入，可通过可见性选择结果；一次撤销移除本次插入，再继续修图。
成功插入后可显示 Windows 系统通知，开关位于面板底部。

## 保存文件与 XCF 数据

展开“生成配置”，使用以下操作：

- “文件另存为”：通过 Windows 文件选择框将提示词、模型和生成参数保存到 `.txt` 文件，内容为 UTF-8 INI 格式。
- “载入文件”：从选定路径读取配置，保留面板当前模式，恢复通用参数及当前模式适用的参数。
- “保存文件”：将更改写回当前文件；首次保存时选择路径。
- “保存到图像”：手动将当前生成配置附加到目标图像，随后保存 `.xcf`。
- “从图像载入”：手动恢复当前目标图像附加的生成配置。

同一配置文件可用于三种模式；例如降噪强度在 img2img 和 inpaint 下生效。各模式字段随文件一同保留。
窗口关闭时保存上次参数、当前文件路径、窗口宽高和通知开关，重开面板时恢复。
XCF 附加数据由“保存到图像”更新，参与 GIMP 撤销，并在 XCF 保存重开后保留。

## LoRA 与 ControlNet

按 LoRA 名称或别名搜索，单击模型将 `<lora:标识:权重>` 加入正向提示词；再次单击移除该模型标签。
权重直接在提示词标签中编辑，支持负数和 `0`。新增标签使用 Forge 的默认权重，名称与分隔符沿用 Forge 设置。
“刷新 LoRA”重新扫描 Forge 目录，“LoRA 详情”显示模型路径和 metadata。标签随提示词一起保存到文件或图像。

ControlNet 支持两组输入。启用对应组，选择当前目标图像内的输入图层，展开参数设置预处理器、模型、权重及起止进度。
“读取图层设置”载入通过“将当前图层配置为 ControlNet 输入”保存的参数。切换目标后重新选择输入图层。
预处理阈值的含义由所选模块决定；Reference 预处理器可使用模型 `None`。

“只导入生成候选”开启时导入候选；关闭时同时导入 ControlNet 返回的预处理图或参考图。该开关适用于三种生成模式。

## Windows 分屏与快捷键

拖动面板边缘调整宽高，最小尺寸为 360×480。拖动 GIMP 标题栏到屏幕一侧，再选择面板完成 Windows 分屏；可拖动分界调整比例。

1. 在 GIMP 中打开“编辑 → 键盘快捷键”。
2. 搜索 `stable-gimpfusion-generate-current` 或“按当前参数生成”。
3. 选择快捷键列，按 `Ctrl+Alt+G` 并保存。
4. 设置面板参数，回到画布绘画，再按快捷键生成。

快捷键接收 GIMP 当前图像，使用面板中的当前模式与参数。面板关闭时会恢复上次参数并生成；已有面板接收本次调用。

## 翻译与开发

使用 GNU gettext 更新翻译：

```bash
bash update-translations.sh
```

脚本提取生产模块文本，合并 en、it、ru、zhcn 四种译文，检查完整性和格式占位符并编译 `.mo`。
中文译文维护在 `locale/zhcn/LC_MESSAGES`；`locale/zh_CN` 的 `.mo` 由脚本生成，供 GIMP 原生菜单加载。
界面文本通过 `sg_i18n._()` 标记，API 字段、模型、采样器和技术选项使用原文。
